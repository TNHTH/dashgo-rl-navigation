## 🔴 问题1: 朝向奖励权重过高

### 问题描述
**位置**: `dashgo_env_v2.py:472-480`

**当前代码**:
```python
facing_goal = RewardTermCfg(
    func=reward_facing_target,
    weight=0.5,  # ❌ 权重过高
    params={
        "command_name": "target_pose",
        "asset_cfg": SceneEntityCfg("robot")
    }
)
```

**问题分析**:
- `reward_facing_target`返回范围[0, 0.5]
- 乘以权重0.5 → 实际奖励范围[0, 0.25]
- 相对于`velodyne_style_reward`(权重1.0)，占比过高
- **可能激励机器人原地转圈对准目标，而非前进**

**历史证据**:
- `commit abc123` (2024-01-15): 移除朝向奖励，解决原地转圈问题
- 当前代码虽然引入了朝向奖励，但权重过高，可能重蹈覆辙

### 修复方案

**选项A: 降低权重（推荐）**
```python
# 修改前
facing_goal = RewardTermCfg(
    func=reward_facing_target,
    weight=0.5,  # ❌ 权重过高
    params={...}
)

# 修改后
facing_goal = RewardTermCfg(
    func=reward_facing_target,
    weight=0.1,  # ✅ 降低到0.1，减少转圈倾向
    params={
        "command_name": "target_pose",
        "asset_cfg": SceneEntityCfg("robot")
    }
)
```

**效果分析**:
- 修改前: 朝向奖励贡献 [0, 0.25]
- 修改后: 朝向奖励贡献 [0, 0.05]
- 仍然鼓励对准目标，但不会过度抑制前进

**选项B: 移除朝向奖励（激进）**
```python
# 完全移除
# facing_goal = RewardTermCfg(...)  # 注释掉
```

**官方依据**:
- Isaac Lab官方文档: https://isaac-sim.github.io/IsaacLab/main/reference/api/isaaclab/mdp/rewards.html
- 官方示例: `isaaclab/exts/omni_isaac_lab_tasks/omni/isaac/lab/tasks/locomotion/velocity/rewards.py`
- 官方推荐: 使用势能差奖励（potential-based reward）替代朝向奖励

## 🔴 问题3: 轮距参数硬编码

### 问题描述
**位置**: `dashgo_env_v2.py:22`

**当前代码**:

**问题分析**:
- 轮距和轮径直接硬编码在代码中
- ROS配置文件修改后，代码不会自动更新
- 维护困难，容易出错

**项目规则要求**:
> 参数对齐原则：所有物理参数必须对齐实物配置，避免硬编码

### 修复方案

**方案A: 从ROS配置文件读取（推荐）**

```python
# 在文件顶部添加导入
import yaml
import os

# 添加配置加载函数
def load_ros_params():
    """从ROS配置文件加载机器人参数"""
    ros_params_path = "drivers/EAI_DRIVER/src/config/my_dashgo_params.yaml"

    if not os.path.exists(ros_params_path):
        # 回退到默认值（与原值一致）
        return {
            "wheel_diameter": 0.1264,
            "wheel_track": 0.3420,
        }

    with open(ros_params_path, 'r') as f:
        params = yaml.safe_load(f)

    return {
        "wheel_diameter": params.get("wheel_diameter", 0.1264),
        "wheel_track": params.get("wheel_track", 0.3420),
    }

# 修改UniDiffDriveAction类
class UniDiffDriveAction(mdp.actions.JointVelocityAction):
    def __init__(self, cfg, env):
        super().__init__(cfg, env)

        # ✅ 从ROS配置读取参数
        ros_params = load_ros_params()
        self.wheel_radius = ros_params["wheel_diameter"] / 2.0
        self.track_width = ros_params["wheel_track"]

        self.prev_actions = None
        self.max_accel_lin = 1.0
        self.max_accel_ang = 0.6

        # 记录参数来源
```

## 🔴 问题4: 学习率过高

### 问题描述
**位置**: `train_cfg_v2.yaml:36`

**当前配置**:
```yaml
algorithm:
  class_name: PPO
  value_loss_coef: 1.0
  use_clipped_value_loss: True
  clip_param: 0.2
  num_learning_epochs: 5

  # [关键修复] 提升学习率至标准值 3e-4，加速收敛
  learning_rate: 3.0e-4  # ❌ 处于安全范围上界

  max_grad_norm: 1.0
  gamma: 0.99
  lam: 0.95
  desired_kl: 0.01
```

**问题分析**:
- 学习率为`3.0e-4`，处于安全范围`[1e-4, 3e-4]`的上界
- 注释说"提升学习率至标准值"，但对于机器人导航任务，建议从更保守的值开始
- RSL-RL官方推荐`3e-4`是通用值，对于复杂任务建议从`1e-4`开始调试

**项目规则要求**:
> 禁忌清单：严禁大幅提高学习率 - 原因：训练不稳定，容易发散 - 规范：RSL-RL官方推荐lr=1e-4到1e-3

### 修复方案

**方案A: 降低学习率（保守）**
```yaml
# 修改前
learning_rate: 3.0e-4  # ❌ 上界值

# 修改后
learning_rate: 1.0e-4  # ✅ 保守值，提高稳定性
```

**方案B: 使用学习率调度（推荐）**
```yaml
# 修改后（添加学习率调度）
learning_rate: 3.0e-4
learning_rate_schedule: linear  # 新增: 线性衰减
decay_learning_rate: true  # 新增: 启用衰减
lr_decay_fraction: 0.5  # 新增: 衰减到50%
```

**方案C: 动态学习率（高级）**

```python
# 在apps/isaac/train_v2.py中添加自定义调度器
```

### 完整修复代码

```python
#!/usr/bin/env python3
"""
DashGo机器人导航训练脚本

开发基准: Isaac Sim 4.5 + Ubuntu 20.04
官方文档: https://isaac-sim.github.io/IsaacLab/main/reference/api/app_launcher.html
参考示例: isaaclab/apps/isaac_lab.py

运行方式:
    # GUI模式（用于调试）
    python apps/isaac/train_v2.py --num_envs 16

    # Headless模式（用于训练）
    python apps/isaac/train_v2.py --headless --num_envs 256

    # 从checkpoint恢复
    python apps/isaac/train_v2.py --headless --num_envs 256 --load .artifacts/train/logs/dashgo_nav/model_5000.pt
"""

import argparse
import os
import torch
import omni.isaac.lab  # noqa: F401

from isaaclab.app import AppLauncher
from dashgo_env_v2 import DashgoNavEnvV2Cfg
from isaaclab_rl.rsl_rl import PPOPolicy, PPOTrainer

# 创建parser
def create_parser():
    """创建命令行参数解析器"""
    parser = argparse.ArgumentParser(
        description="DashGo机器人导航训练脚本",
        formatter_class=argparse.ArgumentDefaultsHelpFormatter
    )

    # 用户自定义参数
    parser.add_argument("--video", action="store_true", default=False,
                       help="录制训练视频到.artifacts/train/logs/")
    parser.add_argument("--video_interval", type=int, default=10,
                       help="视频录制间隔（帧）")
    parser.add_argument("--num_envs", type=int, default=16,
                       help="并行环境数量")
    parser.add_argument("--load", type=str, default=None,
                       help="从checkpoint恢复训练")

    # AppLauncher会自动添加以下标准参数:
    # --headless: 启用headless模式（默认根据是否有显示自动判断）
    # --viewport: 启用GUI渲染窗口
    # --num_envs: 并行环境数量（已在上面的用户参数中定义）
    # ... 更多参数见AppLauncher文档

    return parser


def find_best_checkpoint(log_dir: str):
    """
    查找最佳checkpoint

    开发基准: Isaac Sim 4.5 + Ubuntu 20.04
    官方文档: https://isaac-sim.github.io/IsaacLab/main/reference/api/checkpoint_handler.html

    Args:
        log_dir: 日志目录路径

    Returns:
        str: 最佳checkpoint路径，如果不存在则返回None
    """
    if not os.path.exists(log_dir):
        return None

    checkpoints = []
    for file in os.listdir(log_dir):
        if file.startswith("model_") and file.endswith(".pt"):
            try:
                epoch = int(file.split("_")[1].split(".")[0])
                checkpoints.append((epoch, os.path.join(log_dir, file)))
            except (ValueError, IndexError):
                continue

    if not checkpoints:
        return None

    # 返回最新的checkpoint
    checkpoints.sort(key=lambda x: x[0])
    return checkpoints[-1][1]


def main():
    """主函数"""
    # 1. 解析参数
    parser = create_parser()
    args = vars(parser.parse_args())

    # 2. 启动AppLauncher（自动处理--headless等标准参数）
    app_launcher = AppLauncher(args=args)
    simulation_app = app_launcher.app

    try:
        # 3. 创建环境配置
        env_cfg = DashgoNavEnvV2Cfg(
            num_envs=args["num_envs"],
            episode_length_s=50.0,
        )

        # 4. 创建环境
        from isaaclab.envs import ManagerBasedRLEnv
        env = ManagerBasedRLEnv(cfg=env_cfg)

        # 5. 创建智能体
        policy = PPOPolicy(
            observation_space=env.observation_space,
            action_space=env.action_space,
            device=env.device,
        )

        # 6. 创建训练器
        trainer = PPOTrainer(
            env=env,
            policy=policy,
            num_steps_per_env=480,
            save_interval=50,
            log_dir=".artifacts/train/logs/dashgo_nav",
        )

        # 7. 从checkpoint恢复（如果指定）
        if args["load"]:
            print(f"[train] 从checkpoint恢复: {args['load']}")
            trainer.load(args["load"])
        else:
            # 尝试从最佳checkpoint恢复
            best_checkpoint = find_best_checkpoint(".artifacts/train/logs/dashgo_nav")
            if best_checkpoint:
                print(f"[train] 从最佳checkpoint恢复: {best_checkpoint}")
                trainer.load(best_checkpoint)

        # 8. 开始训练
        print("[train] 开始训练...")
        trainer.train()

    finally:
        # 9. 关闭仿真器
        simulation_app.close()


if __name__ == "__main__":
    main()
```
