## 🎯 为什么要清理旧模型？

### 1. 避免混淆
```
v5.0模型（旧）:
- LiDAR: 1000射线
- action_smoothness: 刷分漏洞
- shaping_distance: 梯度消失
- 课程学习: 失效（只完成1.3%）

v6.0模型（新）:
- LiDAR: 360射线
- action_smoothness: 正确惩罚
- shaping_distance: 完整引导
- 课程学习: 自动适配
```

### 2. 防止错误加载
```bash
# 如果不清理，可能误加载旧模型
python train_v2.py --resume  # 可能加载model_3800.pt（旧模型）

# 清理后，必须从头训练（正确）
python train_v2.py  # ✅ 从零开始
```

### 3. 节省磁盘空间
```
清理前: logs/ + logs/model_*.pt
清理后: logs/ + logs/old_models_v5/model_*.pt

如果不再需要旧模型，可以手动删除:
rm -rf logs/old_models_v5/
```
