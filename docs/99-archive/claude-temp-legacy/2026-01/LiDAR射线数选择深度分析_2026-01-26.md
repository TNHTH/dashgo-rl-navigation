## 📊 核心参数对比

### 技术规格对比

| 指标 | 1000射线 | 360射线 | 差异 |
|------|---------|---------|------|
| **角度分辨率** | 0.36° | 1.0° | 360更稀疏 |
| **每扇区射线数** | 28条 | 10条 | 1000更密集 |
| **降采样方法** | min(28条) | min(10条) | 逻辑相同 |
| **最终维度** | 36维 | 36维 | **相同！** |

### 关键洞察

**最重要的发现**：
```
无论1000还是360，最终都降采样到36维！
差异仅在于：28条取最小值 vs 10条取最小值
```

**数学原理**：
- 最小值函数对冗余数据不敏感
- 10条射线取最小值 vs 28条射线取最小值
- **差异通常 < 5%**

### 仿真vs实物对齐

| 参数 | 仿真1000 | 仿真360 | 实物EAI F4 | 对齐度 |
|------|---------|---------|-----------|--------|
| 点数/圈 | 1000 | 360 | 360-720 | ✅ 360更接近 |
| 角度分辨率 | 0.36° | 1.0° | 0.5-1.0° | ✅ 360更接近 |
| 最大距离 | 12m | 12m | 12-16m | ✅ 仿真保守 |
| 安装高度 | 0.13m | 0.13m | 0.13m | ✅ 完全一致 |
| 最终维度 | 36维 | 36维 | 36维 | ✅ 完全一致 |

**关键点**：
- 360射线**更接近实物规格**
- 降采样逻辑完全相同（36扇区）
- 部署代码**完全一样**

### 部署代码（两者相同）

```python
# ROS节点 - 实物部署
def process_real_lidar(scan_msg):
    ranges = np.array(scan_msg.ranges)  # [720] 或 [360]

    # 降采样到36扇区（对齐仿真）
    sector_size = len(ranges) // 36  # 720÷36=20 或 360÷36=10
    sectors = ranges.reshape(36, sector_size).min(axis=1)
    # [36]

    return sectors / 12.0  # 归一化
```

**结论**：无论仿真用1000还是360，**部署代码完全相同**！
