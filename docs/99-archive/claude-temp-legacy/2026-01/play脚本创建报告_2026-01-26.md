## 📝 Play.py功能

### 核心功能

1. **模型加载**
   - 支持指定checkpoint路径
   - 自动查找logs目录最新模型
   - 使用`OnPolicyRunner.load()`加载

2. **推理模式**
   - 调用`runner.eval_mode()`切换
   - 使用`runner.get_inference_policy()`获取策略
   - 无梯度计算，确定性动作

3. **运行模式**
   - GUI模式：可视化观察（默认8个环境）
   - Headless模式：快速测试（可用更多环境）
   - 视频录制：支持--video参数

4. **统计信息**
   - Episode计数
   - 平均奖励
   - 成功率统计

### 运行示例

```bash
# GUI模式（可视化，推荐）
python play.py --num_envs 8 --checkpoint logs/model_2500.pt

# 使用最新模型
python play.py --num_envs 8

# Headless模式（快速测试）
python play.py --headless --num_envs 32 --checkpoint logs/model_2500.pt

# 限制运行episodes数
python play.py --num_envs 8 --num_episodes 100
```

## 🔧 API参考

### RSL-RL官方API使用

```python
# 1. 创建Runner（不需要训练）
runner = OnPolicyRunner(env, agent_cfg, log_dir=None, device=device)

# 2. 加载模型（不需要optimizer）
runner.load(checkpoint_path, load_optimizer=False)

# 3. 切换到评估模式
runner.eval_mode()

# 4. 获取推理策略
policy = runner.get_inference_policy(device=device)

# 5. 运行推理（无梯度）
with torch.no_grad():
    actions = policy(obs)
    obs, rewards, dones, extras = env.step(actions)
```

## 📚 兼容性说明

### v5.0 vs v6.0模型兼容性

| 特性 | v5.0模型 | v6.0模型 | 兼容性 |
|------|----------|----------|--------|
| LiDAR射线数 | 1000 | 360 | ✅ 降采样后都是36维 |
| 观测维度 | 138 | 138 | ✅ 完全一致 |
| 动作空间 | 2 (线速度+角速度) | 2 | ✅ 完全一致 |
| 网络架构 | [512,256,128] | [512,256,128] | ✅ 完全一致 |
| **结论** | **可以互相加载** | **可以互相加载** | ✅ **完全兼容** |

**原因**：
- LiDAR降采样函数 (process_lidar_ranges) 将1000或360射线都压缩到36维
- 观测空间 = (36 LiDAR + 10 其他状态) × 3帧 = 138维
- 网络输入维度一致，权重可以互相加载
