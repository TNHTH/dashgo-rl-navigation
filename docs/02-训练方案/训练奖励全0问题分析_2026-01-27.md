### 2.2 配置问题：权重为0.0

#### 问题A: alive_penalty - 权重为0

**代码位置**: `dashgo_env_v2.py:1306`

```python
# 配置文件中的定义
alive_penalty = RewardTermCfg(func=reward_alive, weight=0.0)  # ❌ 权重为0
```

**根本原因**：
- 配置中明确设置 `weight=0.0`
- 即使 `reward_alive()` 函数返回-1.0，乘以0后仍为0
- **alive_penalty完全失效**

**影响**：
- 原本设计：每帧惩罚-1.0，逼迫机器人动起来
- 实际效果：机器人可以原地不动，没有生存压力

**函数实现** (`dashgo_env_v2.py:729-731`):
```python
def reward_alive(env: ManagerBasedRLEnv) -> torch.Tensor:
    # 返回 -1.0 * 权重
    return -REWARD_CONFIG["alive_penalty"] * torch.ones(env.num_envs, device=env.device)
```

**为什么设置为0**？
- 可能是历史遗留配置
- 或者是为了调试某个问题临时禁用
- 忘记恢复

### 2.3 Headless模式限制：reward_collision硬编码为0

#### 问题C: collision惩罚 - Headless模式禁用

**代码位置**: `dashgo_env_v2.py:674-686`

```python
# [4] 避障惩罚
# [兼容] headless 模式下传感器不存在，跳过避障惩罚
if sensor_cfg is not None:
    depth_radial = _get_corrected_depth(env, sensor_cfg)

    safe_dist = REWARD_CONFIG["safe_distance"]
    reward_collision = torch.zeros_like(min_dist)
```

**为什么传感器为None**：

**影响**：

### 2.4 阈值过于严格：惩罚项难以触发

#### 问题D: undesired_contacts - 阈值过低

**代码位置**: `dashgo_env_v2.py:432-467` (函数定义), `dashgo_env_v2.py:1286-1293` (配置)

```python
# 函数定义
def penalty_undesired_contacts(env: ManagerBasedRLEnv, sensor_cfg: SceneEntityCfg, threshold: float = 0.1) -> torch.Tensor:
    """轻微接触惩罚 - 第二层防御"""
    contact_data = env.scene[sensor_cfg.name].data.net_forces_w  # [N, num_bodies, 3]
    force_mag = torch.norm(contact_data, dim=-1).max(dim=1)[0]  # [N]
    has_contact = force_mag > threshold  # threshold=0.1N
    return -torch.where(has_contact, 1.0, 0.0)

# 配置
undesired_contacts = RewardTermCfg(
    func=penalty_undesired_contacts,
    weight=-1.0,
    params={
        "sensor_cfg": SceneEntityCfg("contact_forces_base"),
        "threshold": 0.1  # ❌ 0.1牛顿，极低的阈值
    }
)
```

**根本原因**：
- **阈值0.1N太低**，几乎不会触发
- 正常行走时的接触力可能就超过0.1N
- 或者相反，接触力从未达到0.1N（传感器问题）

**分析**：
- 0.1N ≈ 10克重量
- 机器人重量约20kg，轻微碰撞力远大于0.1N
- 如果为0，可能是：
  1. 接触力传感器未正常工作
  2. 相机数据问题导致未正确检测碰撞

#### 问题E: unsafe_speed_penalty - 距离阈值过严

**代码位置**: `dashgo_env_v2.py:376-429` (函数定义), `dashgo_env_v2.py:1295-1304` (配置)

```python
# 函数定义
def penalty_unsafe_speed(env: ManagerBasedRLEnv, asset_cfg: SceneEntityCfg, min_dist_threshold: float = 0.25) -> torch.Tensor:
    """速度-距离 动态约束"""
    # 获取相机数据
    d_front = env.scene["camera_front"].data.output["distance_to_image_plane"]
    d_left = env.scene["camera_left"].data.output["distance_to_image_plane"]
    d_back = env.scene["camera_back"].data.output["distance_to_image_plane"]
    d_right = env.scene["camera_right"].data.output["distance_to_image_plane"]

    # 拼接并展平
    all_pixels = torch.cat([d_front, d_left, d_back, d_right], dim=1).view(batch_size, -1)
    all_pixels = torch.nan_to_num(all_pixels, posinf=12.0)
    min_dist = torch.min(all_pixels, dim=1)[0]

    # 获取速度
    vel = env.scene[asset_cfg.name].data.root_lin_vel_b[:, 0]

    # 计算惩罚：距离 < 0.25m 时，限制最大速度
    safe_vel_limit = torch.clamp(min_dist, max=0.5)
    overspeed = torch.clamp(vel - safe_vel_limit, min=0.0)
    return -overspeed

# 配置
unsafe_speed_penalty = RewardTermCfg(
    func=penalty_unsafe_speed,
    weight=-5.0,
    params={
        "asset_cfg": SceneEntityCfg("robot"),
        "min_dist_threshold": 0.25  # ❌ 0.25m安全距离
    }
)
```

**根本原因**：
- **需要同时满足**：
  1. 距离 < 0.25m（很近）
  2. 速度 > 0.25m/s（较快）
- 这种情况可能很少发生，所以惩罚为0

**分析**：
- 机器人半径约0.2m，加上0.05m余量 = 0.25m
- 几乎贴到障碍物才会触发
- 可能机器人训练策略已经避开了这么近的距离

2. **Headless限制**: collision惩罚在无GUI模式下硬编码为0
3. **阈值问题**: undesired_contacts、unsafe_speed等项阈值过严/过低，难以触发
4. **设计问题**: out_of_bounds、reach_goal等项阈值可能不符合实际场景

**建议修复顺序**：
1. **P0**（立即修复）:
   - 恢复alive_penalty权重（0→-0.05）
   - 修复Headless模式collision惩罚（改用相机数据）

2. **P1**（尽快修复）:
   - 调整undesired_contacts阈值（0.1N→5N）
   - 放宽reach_goal阈值（0.5m→1.0m）
   - 降低unsafe_speed距离阈值（0.25m→0.5m）

3. **P2**（可选优化）:
   - 调整out_of_bounds边界（根据场地实际大小）
   - 添加调试日志，监控各函数调用

### 6.3 风险提示

**如果完全不修复**：
- ❌ 训练无法收敛（奖励信号缺失）
- ❌ 浪费计算资源（无效训练）
- ❌ 无法部署到实物（策略学不到避障）

**如果只修复部分**：
- 🟡 alive_penalty: 机器人会动起来，但可能乱撞
- 🟡 collision: 机器人学会避障，但可能原地不动
- ✅ 两者都修复: 机器人学会"既动又避"
