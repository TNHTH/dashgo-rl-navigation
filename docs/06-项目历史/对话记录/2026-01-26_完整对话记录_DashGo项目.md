## 3. 关键问题与解决方案

### 3.1 问题1: no_norm模式加载失败

**现象**:
```
RuntimeError: Unexpected key(s) in state_dict:
    actor_obs_normalizer._mean
```

**原因**:
- 训练时归一化开启（保存了参数）
- 推理时归一化关闭（网络结构不同）

**解决方案**:
删除归一化参数当disable_norm=True时:
```python
if not enable_norm:
    keys_to_remove = [k for k in model_state_dict.keys() if 'normalizer' in k]
    for key in keys_to_remove:
        del model_state_dict[key]
```

**状态**: ✅ 已解决

---

### 3.2 问题2: RayCaster多mesh限制

**核心限制**:
> **"RayCaster currently only supports one mesh prim"**

**问题根源**:
- Isaac Lab v0.46.4的RayCaster基于Warp加速
- Warp模式强制：`mesh_prim_paths`必填 + 长度=1
- 不支持多mesh场景（地面+16个障碍物）

**尝试过程**:
1. 添加17个物体 → `NotImplementedError: Received: 17`
2. 设为None → `TypeError: NoneType has no len()`
3. 删除参数 → `Missing values detected`
4. Monkey Patch → `TypeError: 'NoneType' object is not subscriptable`

**结论**:
**RayCaster硬耦合Warp，无法使用PhysX模式**

**解决方案**:
用深度相机模拟LiDAR（`CameraCfg` + `distance_to_image_plane`）

**优势**:
- ✅ 基于PhysX/渲染，能看到所有障碍物
- ✅ 不受Warp Mesh限制
- ✅ Sim-to-Real标准做法

**状态**: ✅ 已解决

---

### 3.3 问题3: 奖励函数冲突

**发现**: 两个`reward_target_speed`定义

**定义1**（line 409，正确）:
```python
def reward_target_speed(env, asset_cfg):
    vel = env.scene[asset_cfg.name].data.root_lin_vel_b[:, 0]
    return torch.clamp(vel, min=0.0)  # 只奖励前进
```

**定义2**（line 568，错误）:
```python
def reward_target_speed(env: ManagerBasedRLEnv, asset_cfg: SceneEntityCfg) -> torch.Tensor:
    target_vel = 0.25
    speed_match = 1.0 - torch.abs(lin_vel_b - target_vel) / target_vel
    return torch.clamp(speed_match, 0.0, 0.2)  # 奖励任意方向！
```

**影响**:
Python使用最后一个定义 → 机器人学会"倒车刷分" → "醉汉走路"

**解决方案**:
删除第二个（错误）定义，保留第一个（正确）定义

**状态**: ✅ 已解决

## 4. 技术发现与经验教训

### 4.1 Isaac Lab版本限制

**发现**: Isaac Lab v0.46.4的`RayCaster`存在架构限制
- 基于Warp加速，只支持单一mesh
- 无法切换到PhysX模式（代码硬耦合）
- 不适用于多mesh场景

**教训**:
- 版本限制很重要
- 需要查阅官方文档确认API能力
- 某些功能在特定版本可能不可用

### 4.2 Python函数覆盖机制

**发现**: Python使用最后一个函数定义

**示例**:
```python
def func(): ...  # 第一个
def func(): ...  # 第二个（生效）

# 最终生效：第二个
```

**教训**:
- 同名函数必须确保只有一个版本
- 代码审查时检查函数重复定义
- 使用IDE搜索确认无重复

### 4.3 调试方法论

**三嫌疑人框架**:
1. 坐标系（检查变换矩阵）
2. 归一化（关闭测试）
3. 物理参数（检查URDF）

**扩展方法**:
- 创建专用诊断工具
- 逐步排除嫌疑人
- 深度数据分析（唯一值数量）

**教训**:
- 系统化排查比盲目尝试更高效
- 工具先行（debug脚本）
- 数据说话（观测统计）

### 4.4 Sim-to-Real策略

**发现**: 深度相机模拟LiDAR是标准做法

**原理**:
- 使用`CameraCfg(depth)`生成深度图
- 数据在数学上等同于单线激光雷达
- 能看到所有物理碰撞体

**优势**:
- 不受Warp Mesh限制
- Sim-to-Real对齐简单
- 业界标准方案

### 8.3 数据处理适配

**替换前**（RayCaster）:
```python
def _compute_raycaster_distance(env, sensor_cfg):
    sensor = env.scene[sensor_cfg.name]
    ray_hits_w = sensor.data.ray_hits_w  # [N, 360, 3]
    sensor_pos_w = sensor.data.pos_w       # [N, 3]
    vec = ray_hits_w - sensor_pos_w.unsqueeze(1)
    dist = torch.norm(vec, dim=-1)
    return dist  # [N, 360]
```

**替换后**（Camera）:
```python
def _compute_raycaster_distance(env, sensor_cfg):
    sensor = env.scene[sensor_cfg.name]
    depth_image = sensor.data.output["distance_to_image_plane"]  # [N, 1, 180]
    ranges = depth_image.squeeze(dim=1)  # [N, 180]
    max_range = 10.0
    ranges = torch.nan_to_num(ranges, posinf=max_range, neginf=0.0)
    ranges = torch.clamp(ranges, min=0.0, max=max_range)
    return ranges  # [N, 180]
```
