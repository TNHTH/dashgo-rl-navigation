## ✅ 已创建的文件

### 1. connect_to_robot.sh - ROS多机连接脚本

**路径**：`~/dashgo_rl_project/connect_to_robot.sh`

**用途**：自动化配置ROS多机通讯，测试与机器人的连接

**架构师修正点**：
- ✅ **智能IP获取**：优先抓取192.168开头的局域网IP
- ✅ **交互式确认**：如果自动识别失败，提示用户手动输入
- ✅ **连接测试**：自动测试ROS Master连通性
- ✅ **友好提示**：提供详细的故障排查建议

**使用方法**：
```bash

./connect_to_robot.sh

# 直接指定IP
./connect_to_robot.sh 192.168.5.100
```

## ⚙️ 环境准备（首次使用）

### 步骤1：创建dashgo_deploy环境

```bash
# 创建Python 3.8环境
conda create -n dashgo_deploy python=3.8 -y
conda activate dashgo_deploy

# 安装PyTorch（CPU版）
pip install torch==1.10.0 torchvision==0.11.0

# 安装ROS桥接库
pip install rospkg defusedxml netifaces numpy empy
```

### 步骤2：编译ROS工作空间

```bash
cd ~/dashgo_rl_project/workspaces/ros1_catkin_ws

# 清理旧编译
rm -rf build devel

# 显式指定Python路径编译
catkin_make -DPYTHON_EXECUTABLE=$(which python)

# 刷新环境
source devel/setup.bash
```

## 🔍 故障排查

### 问题1：无法连接到ROS Master

**症状**：
```bash
rostopic list
# ERROR: Unable to communicate with master!
```

**解决**：
1. 检查网络：`ping 192.168.5.100`
2. 检查roscore：`ssh 192.168.5.100 "ps aux | grep roscore"`
3. 检查环境变量：`echo $ROS_MASTER_URI`（应为http://192.168.5.100:11311）

---

### 问题2：模型加载失败

**症状**：
```
❌ 模型加载失败: [Errno 2] No such file or directory: 'models/policy_torchscript.pt'
```

**解决**：
1. 检查模型文件是否存在：`ls -lh workspaces/ros1_catkin_ws/src/dashgo_rl/models/policy_torchscript.pt`
2. 如果不存在，运行导出脚本：`~/IsaacLab/isaaclab.sh -p apps/isaac/export_torchscript.py`

---

### 问题3：conda activate在脚本中不工作

**症状**：
```
conda activate dashgo_deploy
# command not found: conda
```

**解决**：
在脚本中source conda.sh：
```bash
source ~/miniconda3/etc/profile.d/conda.sh  # 或anaconda3
conda activate dashgo_deploy
```

或者手动激活环境后再运行脚本。

| 参数 | 值 | 来源 |
|------|-----|------|
| **最大线速度** | 0.3 m/s | MOTION_CONFIG |
| **最大角速度** | 1.0 rad/s | MOTION_CONFIG |
| **轮子直径** | 0.1264 m | DashGoPhysicalSpecs |
| **轮距** | 0.3420 m | DashGoPhysicalSpecs |

| **扫描频率** | 7 Hz | scan_frequency_default |
| **雷达点数** | 720 点/圈 | data_points_per_scan |

| 参数 | 值 | 说明 |
|------|-----|------|
| **输入维度** | 246 | 72(LiDAR) × 3帧 + 30(其他) |

| **历史帧数** | 3 | ObservationBuffer |
