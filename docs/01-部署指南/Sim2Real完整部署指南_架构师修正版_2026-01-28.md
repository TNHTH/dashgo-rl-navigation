## 📋 部署前准备

### 硬件要求

| 组件 | 型号 | 说明 |
|------|------|------|
| **计算平台** | Jetson Nano 4GB / Ubuntu PC | 必须支持PyTorch |
| **机器人** | DashGo D1 | 差速驱动底盘 |
| **LiDAR** | EAI F4 | 360°，720点 |
| **操作系统** | Ubuntu 20.04 + ROS Noetic | 必须匹配 |

### 软件要求

```bash
# ROS Noetic
sudo apt install ros-noetic-desktop

# PyTorch (CPU版本)
pip install torch==1.10.0 torchvision==0.11.0

# 或Jetson上使用l4t-pytorch
# 参考: https://github.com/Qengineering/PyTorch-Jetson
```

### ⚠️ [重要] 环境准备检查表

在启动ROS节点前，**必须**先检查Python环境：

```bash
# 1. 检查Python版本（需要3.7+）
python3 --version
# 预期: Python 3.7+

# 2. 检查PyTorch是否已安装
python3 -c "import torch; print('PyTorch版本:', torch.__version__)"
# 预期: PyTorch版本: 1.10.0

# 3. 如果报错"ModuleNotFoundError: No module named 'torch'"
#    则需要先安装PyTorch（见下方安装指南）
```

### 🔧 PyTorch安装指南

#### 选项A：在当前环境安装（快速测试）

```bash
# CPU版本（适用于PC/笔记本）
pip install torch==1.10.0 torchvision==0.11.0

# GPU版本（如果有CUDA）
pip install torch==1.10.0+cu111 torchvision==0.11.0+cu111
```

#### 选项B：创建专用部署环境（推荐）

```bash
# 创建新环境
conda create -n dashgo_deploy python=3.8

# 激活环境
conda activate dashgo_deploy

# 安装PyTorch
pip install torch==1.10.0 torchvision==0.11.0

# 安装ROS Python依赖
pip install ros-noetic-tf2-geometry-msgs

# 返回项目目录
cd ~/dashgo_rl_project
```

#### 选项C：使用Isaac Lab环境（临时方案）

```bash
# 激活Isaac Lab环境（包含PyTorch）
conda activate env_isaaclab

# 验证PyTorch
python3 -c "import torch; print(torch.__version__)"

# 继续部署流程
```

**注意**：
- env_isaaclab环境较重，可能影响ROS性能
- 建议创建专用的轻量级部署环境

## 🐛 常见问题排查

### 问题1：维度不匹配

**症状**：
```
RuntimeError: mat1 and mat2 shapes cannot be multiplied: [1, 77] vs [1, 246]
```

**原因**：
- 使用了助手版本的节点（77维）
- 模型需要246维

**解决**：
```bash
# 确认使用的是架构师修正版节点
head -20 workspaces/ros1_catkin_ws/src/dashgo_rl/scripts/geo_nav_node.py | grep "架构师"
# 应该看到: "# 作者: Isaac Sim Architect"
```

### 问题2：模型加载失败

**症状**：
```
FileNotFoundError: [Errno 2] No such file or directory: 'policy_torchscript.pt'
```

**解决**：
```bash
# 检查模型路径
ls -l workspaces/ros1_catkin_ws/src/dashgo_rl/models/

# 如果没有，运行导出脚本
~/IsaacLab/isaaclab.sh -p apps/isaac/export_torchscript.py
```

### 🚨 问题3：ROS节点启动失败 - 缺少PyTorch依赖

**症状**：
```bash
Traceback (most recent call last):
  File "geo_nav_node.py", line 15, in <module>
    import torch
ModuleNotFoundError: No module named 'torch'
```

**场景**：
- 启动Gazebo成功 ✅
- 启动geo_nav_node节点失败 ❌
- 错误：缺少torch模块

**原因**：
- 当前Python环境没有安装PyTorch
- 训练环境（env_isaaclab）与部署环境（base）分离
- 环境隔离导致依赖缺失

**解决方案**：

##### 方案A：快速修复（适合PC测试）

```bash
# 1. 检查当前环境
conda info --envs

# 2. 在当前环境安装PyTorch
pip install torch==1.10.0 torchvision==0.11.0

# 3. 验证安装
python3 -c "import torch; print('PyTorch版本:', torch.__version__)"

# 4. 重新启动节点
source ~/dashgo_rl_project/workspaces/ros1_catkin_ws/devel/setup.bash
roslaunch dashgo_rl geo_nav.launch
```

##### 方案B：创建专用部署环境（推荐）

```bash
# 1. 创建新环境
conda create -n dashgo_deploy python=3.8 -y

# 2. 激活环境
conda activate dashgo_deploy

# 3. 安装PyTorch
pip install torch==1.10.0 torchvision==0.11.0

# 4. 安装ROS依赖
pip install ros-noetic-tf2-geometry-msgs

# 5. 返回项目并编译
cd ~/dashgo_rl_project/workspaces/ros1_catkin_ws
catkin_make
source devel/setup.bash

# 6. 启动节点
roslaunch dashgo_rl geo_nav.launch
```

##### 方案C：使用Isaac Lab环境（临时方案）

```bash
# 激活Isaac Lab环境（包含PyTorch）
conda activate env_isaaclab

# 验证PyTorch
python3 -c "import torch; print('✅ PyTorch已安装:', torch.__version__)"

# 编译工作空间（首次需要）
cd ~/dashgo_rl_project/workspaces/ros1_catkin_ws
catkin_make
source devel/setup.bash

# 启动节点
roslaunch dashgo_rl geo_nav.launch
```

**注意**：
- env_isaaclab环境较重，可能影响ROS性能
- 建议长期使用方案B（专用部署环境）

**环境管理最佳实践**：
```bash
# 训练环境（env_isaaclab）
conda activate env_isaaclab
~/IsaacLab/isaaclab.sh -p apps/isaac/train_v2.py ...

# 部署环境（dashgo_deploy）

### 问题3：TF查询失败

**症状**：
```
⚠️ TF查询失败

**原因**：
