## 📋 方案概览

```
训练模型 → 导出TorchScript → 编译ROS工作空间 → 启动Gazebo仿真 → 运行RL节点 → RViz可视化
```

## 🚀 阶段1：模型导出（TorchScript）

### 目标
将训练好的PyTorch模型导出为TorchScript格式，用于ROS部署。

### 步骤

#### 1.1 激活Isaac Sim环境

```bash
cd ~/dashgo_rl_project

# 激活Isaac Sim Python环境
source ~/.local/share/isaac-sim/python/setup.sh  # 或你的Isaac Sim安装路径
```

#### 1.2 导出模型

```bash
# 查看最新模型
ls -lht .artifacts/train/logs/model_*.pt | head -1

# 导出最新模型（自动查找）
python apps/isaac/export_torchscript.py

# 或导出指定模型
python apps/isaac/export_torchscript.py --checkpoint .artifacts/train/logs/model_7999.pt
```

**预期输出**:
```
✅ 模型导出成功！
保存路径: workspaces/ros1_catkin_ws/src/dashgo_rl/models/policy_torchscript.pt
模型大小: 1.8 MB
```

#### 1.3 验证导出结果

```bash
# 检查文件是否存在
ls -lh workspaces/ros1_catkin_ws/src/dashgo_rl/models/policy_torchscript.pt

# 应该显示：
# -rw-r--r-- 1 gwh gwh 1.8M ... policy_torchscript.pt
```

### 故障排查

**问题1**: `ModuleNotFoundError: No module named 'isaaclab'`

**解决**:
```bash
# 确保先激活Isaac Sim环境
source ~/.local/share/isaac-sim/python/setup.sh
# 或
source /opt/isaac-sim/python/setup.sh
```

**问题2**: `RuntimeError: model forward() method not found`

**解决**:
```bash
# 检查geo_nav_policy.py版本
head -5 geo_nav_policy.py
# 应该显示 v3.2 或更高版本
```

## 🔨 阶段2：编译ROS工作空间

### 目标
编译dashgo_rl包，确保所有依赖正确安装。

### 步骤

#### 2.1 激活ROS环境

```bash
# 激活ROS Noetic
source /opt/ros/noetic/setup.bash
```

#### 2.2 清理旧编译（可选但推荐）

```bash
cd ~/dashgo_rl_project/workspaces/ros1_catkin_ws

# 清理旧编译
rm -rf build devel
```

#### 2.3 编译工作空间

```bash
# 显式指定Python路径编译
catkin_make -DPYTHON_EXECUTABLE=$(which python)

# 刷新环境
source devel/setup.bash
```

**预期输出**:
```
[100%] Built target dashgo_rl
```

#### 2.4 验证编译结果

```bash
# 检查节点是否可执行
which geo_nav_node.py
# 应该显示：/home/gwh/dashgo_rl_project/workspaces/ros1_catkin_ws/devel/lib/dashgo_rl/geo_nav_node.py

# 检查包路径
rospack find dashgo_rl
# 应该显示：/home/gwh/dashgo_rl_project/workspaces/ros1_catkin_ws/src/dashgo_rl
```

### 故障排查

**问题1**: `CMake Error: Could not find rospkg`

**解决**:
```bash
# 安装rospkg
pip install rospkg

# 重新编译
cd ~/dashgo_rl_project/workspaces/ros1_catkin_ws
catkin_make -DPYTHON_EXECUTABLE=$(which python)
```

**问题2**: `Python import error: No module named torch`

**解决**:
```bash
# 确保使用conda环境（如果使用conda）
conda activate dashgo_deploy

# 或系统Python安装torch
pip install torch==1.10.0
```

## 🎮 阶段4：发送导航目标

### 目标
通过RViz的"2D Nav Goal"工具发送目标点，观察机器人导航。

### 步骤

#### 4.1 在RViz中添加显示

在RViz窗口中：
1. 点击左侧"Add"按钮
2. 添加以下显示项：
   - **RobotModel**: 显示机器人模型
   - **TF**: 显示坐标系
   - **LaserScan**: 显示雷达数据（Topic: `/scan`）
   - **Odometry**: 显示里程计（Topic: `/odom`）

#### 4.2 发送导航目标

1. 在RViz工具栏中选择 **"2D Nav Goal"** 工具
2. 在地图中点击目标位置
3. 拖动鼠标设置目标朝向
4. 松开鼠标发送目标

**预期效果**:
- 终端显示：`🎯 收到新目标: (x.xx, y.yy)`
- 机器人开始运动
- Gazebo中机器人向目标移动
- RViz中显示机器人轨迹

#### 4.3 观察控制命令

在新终端中：

```bash
source ~/dashgo_rl_project/workspaces/ros1_catkin_ws/devel/setup.bash

# 查看速度命令
```

**预期输出**:

## ✅ 阶段5：验证与调优

### 验证清单

#### 5.1 机器人运动验证

- [ ] 机器人能向目标点移动
- [ ] 机器人能避开障碍物（Gazebo中添加障碍物测试）
- [ ] 机器人到达目标点附近停止（< 0.2m）
- [ ] 速度平滑，无剧烈抖动

#### 5.2 安全机制验证

- [ ] 机器人不倒车（倒车会被禁止）
- [ ] 加速度限制生效（不突然加速）
- [ ] 接近目标时自动减速

### 常见问题

**问题1**: 机器人原地转圈

**原因**: 训练未收敛或模型过旧

**解决**:
```bash
# 检查训练曲线
tensorboard --logdir=logs

# 使用最新模型重新导出
python apps/isaac/export_torchscript.py --checkpoint .artifacts/train/logs/model_7999.pt
```

**问题2**: 机器人不动

**原因**: 可能是TF坐标系问题或目标点无效

**解决**:
```bash
# 检查TF树
rosrun tf view_frames
# 或
rosrun rqt_tf_tree rqt_tf_tree

# 检查目标点是否发布
rostopic echo /move_base_simple/goal
```

**问题3**: 速度过慢

**解决**:
```bash
# 修改launch文件中的速度限制
nano workspaces/ros1_catkin_ws/src/dashgo_rl/launch/sim2real_golden.launch

# 找到并修改：
# <arg name="max_lin_vel" default="0.5" />  # 从0.3改为0.5

# 重启launch文件
```

## 🚨 紧急停止

如果机器人失控：

```bash
# 方法1：发布零速度
rostopic pub /cmd_vel geometry_msgs/Twist '{linear: {x: 0.0, y: 0.0, z: 0.0}, angular: {x: 0.0, y: 0.0, z: 0.0}}'

# 方法2：Ctrl+C 停止RL节点
# 在运行roslaunch的终端按 Ctrl+C

# 方法3：停止ROS Master
rosnode kill -a
```

## 📝 故障排查日志

### 常见错误代码

| 错误信息 | 原因 | 解决方案 |
|---------|------|---------|
| `Dimension Mismatch` | 模型输入维度不对 | 重新导出TorchScript模型 |
| `model not found` | 模型路径错误 | 检查launch文件的model_path参数 |
| `TF lookup failed` | 坐标系缺失 | 检查robot_state_publisher是否运行 |
| `No module named 'torch'` | PyTorch未安装 | `pip install torch` |
| `rospkg not found` | 依赖缺失 | `pip install rospkg` |
