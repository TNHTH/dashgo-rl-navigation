#### 步骤1：安装aptitude

```bash
sudo apt update
sudo apt install -y aptitude
```

#### 步骤2：使用aptitude安装navigation

```bash
sudo aptitude install ros-noetic-navigation
```

**关键交互决策**：

**第一问**（保持现状？）：
```
Accept this solution? [Y/n/q/?]
Keep the following packages at their current version:
  ros-noetic-desktop ...

👉 你的选择：输入 n
（理由：我们要安装navigation，不能保持现状）
```

**第二问**（降级libsdl？）：
```
Downgrade the following packages:
  libsdl1.2  2.0-0 → 1.2.15

👉 你的选择：输入 y
（前提：只要没看到"Remove ros-noetic-desktop"）
```

**⚠️ 重要提示**：
- 如果看到"Remove"ros-noetic-desktop"字眼，**坚决输入 n**
- 如果降级方案看起来合理，输入 y
- 如果不确定，可以取消（Ctrl+C）并咨询

#### 步骤3：验证安装

```bash
rospack find move_base
# 应输出：/opt/ros/noetic/share/move_base
```

## 🔧 常见问题

### Q1: aptitude找不到合适的解决方案

**症状**：
```
E: Unable to find a source package for the target version
```

**解决方案**：
```bash
# 1. 添加ROS源（如果还没有）
sudo sh -c 'echo "deb http://packages.ros.org/ros/ubuntu $(lsb_release -sc) main" > /etc/apt/sources.list.d/ros-latest.list'
sudo apt update

# 2. 重试aptitude安装
sudo aptitude install ros-noetic-navigation
```

### Q2: 降级方案会影响其他系统吗？

**架构师分析**：
- SDL1.2是稳定的老旧库，降级风险极低
- 只影响很少的ROS包，不影响其他系统

**恢复方法**（如果降级后出现问题）：
```bash
# 回滚到原版本
sudo apt install libsdl1.2=2.0-0
```

### Q3: 提示"Remove ros-noetic-desktop"

**症状**：系统建议删除ros-noetic-desktop

**解决方案**：
1. 坚决输入：n（拒绝）
2. 或按Ctrl+C取消
3. 尝试其他解决方案
