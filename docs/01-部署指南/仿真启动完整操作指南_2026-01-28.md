## 🚀 第一阶段：环境准备（首次使用，仅需一次）

### 步骤1：检查Python版本

**目的**：确认系统Python版本

```bash
# 检查系统Python 3.8是否已安装
python3.8 --version
```

**预期输出**：
```
Python 3.8.10
```

**如果报错**：
```bash
# 安装Python 3.8
sudo apt update
sudo apt install python3.8 python3.8-dev -y
```

---

### 步骤2：创建dashgo_deploy环境

**目的**：创建专用的Python 3.8环境，安装PyTorch和ROS依赖

```bash
# 1. 创建环境
conda create -n dashgo_deploy python=3.8 -y

# 2. 激活环境
conda activate dashgo_deploy

# 3. 验证Python版本
python --version
# 应该显示：Python 3.8.x
```

**预期输出**：
```
(dashgo_deploy) $ python --version
Python 3.8.18
```

---

### 步骤3：安装PyTorch

**目的**：安装PyTorch CPU版（笔记本够用）

```bash
# 确保在dashgo_deploy环境中
conda activate dashgo_deploy

# 安装PyTorch 1.10.0（与训练环境一致）
pip install torch==1.10.0 torchvision==0.11.0

# 验证安装
python -c "import torch; print('PyTorch版本:', torch.__version__)"
```

**预期输出**：
```
PyTorch版本: 1.10.0
```

**⏱️ 预计时间**：2-5分钟（取决于网络速度）

---

### 步骤4：安装ROS桥接库

**目的**：让conda环境能使用ROS

```bash
# 确保在dashgo_deploy环境中
conda activate dashgo_deploy

# 安装ROS Python依赖
pip install rospkg defusedxml netifaces numpy empy

# 验证
python -c "import rospy; print('✅ ROS可用')"
```

**预期输出**：
```
✅ ROS可用
```

---

### 步骤5：编译ROS工作空间

**目的**：使用dashgo_deploy环境编译，确保所有节点使用正确的Python

```bash
# 1. 进入工作空间
cd ~/dashgo_rl_project/workspaces/ros1_catkin_ws

# 2. 清理旧编译（如果有）
rm -rf build devel install

# 3. 确保在dashgo_deploy环境
conda activate dashgo_deploy

# 4. 显式指定Python路径编译
catkin_make -DPYTHON_EXECUTABLE=$(which python)
```

**预期输出**：
```
[ 50%] Built target dashgo_rl
[100%] Linking CXX executable devel/lib/dashgo_rl/geo_nav_node.py
[100%] Built target dashgo_rl
```

**如果编译成功**：
```bash
# 刷新环境
source devel/setup.bash

# 验证ROS包
rospack list | grep dashgo
```

**预期输出**：
```
dashgo_rl /home/gwh/dashgo_rl_project/workspaces/ros1_catkin_ws/src/dashgo_rl
```

**⏱️ 预计时间**：1-2分钟

### 步骤6：验证模型文件

## 🎯 第三阶段：测试RL导航

### 方法1：使用Rviz发送目标点（推荐）

1. **在Rviz窗口中**：
   - 点击工具栏的 **"2D Nav Goal"** 按钮（绿色箭头图标）

2. **在地图上**：
   - 点击任意位置（目标点）
   - 拖拽鼠标调整方向（车头朝向）
   - 松开鼠标

3. **观察机器人**：
   - Gazebo中的小车应该开始移动
   - Rviz中应该能看到机器人轨迹
   - 终端应该显示导航信息

---

### 方法2：使用命令行发送目标点

```bash
# 发送目标点到 (x=2.0, y=1.0, 朝向东)
rostopic pub /move_base_simple/goal geometry_msgs/PoseStamped "
header:
  frame_id: 'map'
pose:
  position:
    x: 2.0
    y: 1.0
    z: 0.0
  orientation:
    x: 0.0
    y: 0.0
    z: 0.0
    w: 1.0"
```

## 🐛 故障排查

### 问题1：conda command not found

**症状**：
```bash
conda activate dashgo_deploy
# conda: command not found
```

**解决**：
```bash
# 方案A：初始化conda
source ~/miniconda3/bin/activate  # 或anaconda3
conda activate dashgo_deploy

# 方案B：在~/.bashrc中添加conda路径
echo 'export PATH="$HOME/miniconda3/bin:$PATH"' >> ~/.bashrc
source ~/.bashrc
```

---

### 问题2：模型加载失败

**症状**：
```
❌ 模型加载失败: [Errno 2] No such file or directory
```

**解决**：
```bash
# 1. 检查模型文件是否存在
ls -lh ~/dashgo_rl_project/workspaces/ros1_catkin_ws/src/dashgo_rl/models/policy_torchscript.pt

# 2. 如果不存在，重新导出
cd ~/dashgo_rl_project
~/IsaacLab/isaaclab.sh -p apps/isaac/export_torchscript.py
```

---

### 问题3：Gazebo无法启动

**症状**：
```
Resource not found: gazebo_ros
```

**解决**：
```bash
# 安装gazebo_ros
sudo apt install ros-noetic-gazebo-ros ros-noetic-gazebo-plugins -y

# 重新运行
source ~/.bashrc
roslaunch dashgo_rl sim2real_golden.launch
```

---

### 问题4：RL节点启动失败

**症状**：
```
ModuleNotFoundError: No module named 'torch'
```

**解决**：
```bash
# 1. 确认在dashgo_deploy环境
conda activate dashgo_deploy

# 2. 检查PyTorch是否安装
python -c "import torch; print(torch.__version__)"

# 3. 如果没有安装
pip install torch==1.10.0 torchvision==0.11.0

# 4. 重新编译工作空间
cd ~/dashgo_rl_project/workspaces/ros1_catkin_ws
rm -rf build devel
catkin_make -DPYTHON_EXECUTABLE=$(which python)
source devel/setup.bash
```

---

### 问题5：Rviz显示空白

**症状**：Rviz打开但什么都看不到

**解决**：
1. 在Rviz左侧面板，检查 **"Fixed Frame"** 设置
2. 改为 `map` 或 `odom`
3. 点击 **"Add"** 按钮，添加以下显示项：
   - **By topic** → `/scan` → **LaserScan**（显示雷达）
   - **By display type** → **RobotModel**（显示机器人）
   - **By topic** → `/cmd_vel` → **Twist**（显示速度）

## 🎓 进阶操作

### 查看实时话题数据

```bash
# 查看雷达数据
rostopic echo /scan -n 1

# 查看速度命令
rostopic echo /cmd_vel -n 1

# 查看里程计
rostopic echo /odom -n 1
```

---

### 记录仿真数据（bag文件）

```bash
# 创建保存目录
mkdir -p ~/bags/sim_test

# 记录所有话题
rosbag record -O ~/bags/sim_test/sim_test.bag \
  /scan \
  /odom \
  /cmd_vel \
  /move_base_simple/goal

# 按 Ctrl+C 停止记录

# 回放bag文件
rosbag play ~/bags/sim_test/sim_test.bag
```

---

### 调整仿真参数

**编辑launch文件**：
```bash
# 编辑仿真launch文件
nano ~/dashgo_rl_project/workspaces/ros1_catkin_ws/src/dashgo_rl/launch/sim2real_golden.launch

# 修改以下参数：
# - max_lin_vel: 最大线速度（默认0.3 m/s）
# - max_ang_vel: 最大角速度（默认1.0 rad/s）
# - control_rate: 控制频率（默认20 Hz）
```
