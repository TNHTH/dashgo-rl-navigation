## 🔍 根本原因

### API重构

Isaac Lab 在 0.46 版本（对应 Isaac Sim 4.5）重构了MDP（Markov Decision Process）API：

```
旧版API (Isaac Lab < 0.46):
- mdp.randomize_rigid_body_pose

新版API (Isaac Lab >= 0.46):
- mdp.reset_root_state_uniform
- mdp.reset_root_state_random
- mdp.reset_root_state_region
```

### 参数结构调整

**旧版参数结构**：
```python
params={
    "asset_cfg": SceneEntityCfg("obs_.*"),
    "pos_range": {"x": (-0.5, 0.5), "y": (-0.5, 0.5)},
    "rot_range": {"yaw": (-math.pi, math.pi)},
}
```

**新版参数结构**：
```python
params={
    "asset_cfg": SceneEntityCfg("obs_.*"),
    "pose_range": {
        "x": (-0.5, 0.5),
        "y": (-0.5, 0.5),
        "yaw": (-math.pi, math.pi),
    },
    "velocity_range": {},  # 新增：速度范围
}
```

### 变更说明

1. **位置和旋转统一**：`pos_range` + `rot_range` → `pose_range`
2. **新增速度参数**：`velocity_range` (静态物体设为空字典 `{}`)
3. **函数语义更清晰**：`reset_root_state_*` 系列函数

## 🎯 经验总结

### 关键要点

1. **API版本管理**：
   - Isaac Lab 在 0.46 版本进行了大规模API重构
   - 必须明确使用的Isaac Lab版本
   - 查询官方文档时要确认版本号

2. **错误诊断技巧**：
   - `AttributeError: module has no attribute` → API不存在或已重命名
   - 检查import语句和API调用
   - 查看官方文档的变更日志

3. **参数结构变化**：
   - 新版API倾向于统一参数结构
   - `pose_range` 包含位置和旋转
   - 新增 `velocity_range` 以支持动态物体

4. **验证流程**：
   - 修改代码后先运行语法检查
   - 再启动训练验证
   - 观察是否有其他兼容性问题
