## 🐛 可能遇到的问题

### 问题1：move_base启动失败

**症状**：
```
[ERROR] [WallTime]: Failed to create the global planner
[ERROR] [WallTime]: Failed to create the local planner
```

**原因**：参数文件路径错误或文件不存在

**解决方案**：
```bash
# 检查参数文件是否存在
ls -lh catkin_ws/src/dashgo_rl/param/

# 如果缺少文件，重新复制
cp dashgo/1/1/nav/param/*.yaml catkin_ws/src/dashgo_rl/param/
```

---

### 问题2：Costmap配置错误

**症状**：
```
[ERROR] [WallTime]: Failed to transform sensor data
[ERROR] [WallTime]: Laser scan observation buffer empty
```

**原因**：激光雷达topic名称不匹配

**解决方案**：
检查 `costmap_common_params.yaml` 中的：
```yaml
observation_sources: laser_scan_sensor
laser_scan_sensor: {sensor_frame: laser_link, ...}
```

确认 `sensor_frame: laser_link` 与URDF中的frame名称一致。

---

### 问题3：DWA规划器失败

**症状**：
```
[WARN] [WallTime]: DWA planner failed to produce path
[WARN] [WallTime]: No valid trajectory found
```

**原因**：
- DWA参数过于保守
- 机器人速度限制太小
- 障碍物太密集

**解决方案**：
调整 `base_local_planner_dwa_params.yaml`：
```yaml
max_vel_x: 0.3        # 确保不是0
min_vel_trans: 0.05   # 降低最小速度
sim_time: 1.7         # 增加前向模拟时间
```

---

### 问题4：TF_REPEATED_DATA警告仍然很多

**症状**：
```
[WARN] [WallTime]: TF_REPEATED_DATA ignoring data with redundant timestamp
for frame left_wheel_link
for frame right_wheel_link
```

**原因**：robot_state_publisher 和 Gazebo 都在发布轮子TF

**影响**：小（TF会取最新时间戳）

**解决方案**（可选）：
修改 `dashgo_d1_sim.urdf.xacro`，禁止Gazebo发布轮子TF：
```xml
<gazebo reference="left_wheel_link">
  <disableFilteredLogging>true</disableFilteredLogging>
</gazebo>
```

#### 步骤1：修改 `dashgo_env_v2.py`

```python
# 在奖励函数中添加转动惩罚
@configclass
class RewardTermCfg:
    shaping_angular_penalty: RewardTermCfg = RewardTermCfg(
        weight=0.5,  # 与参考项目一致
        params={}
    )

def compute_angular_penalty(self, actions: torch.Tensor) -> torch.Tensor:
    """
    计算转动惩罚

    Args:
        actions: 动作 [num_envs, 2]，actions[:,1]是角速度

    Returns:
        penalty: 惩罚值 [num_envs]
    """
    angular_vel = actions[:, 1]
    penalty = torch.abs(angular_vel)
    return penalty
```
