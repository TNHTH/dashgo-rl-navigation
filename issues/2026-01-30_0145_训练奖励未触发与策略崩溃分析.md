## 根本原因分析

### 核心矛盾：奖励-终止悖论 🔴

**观察**：
- `Episode_Termination/reach_goal`: 78% （高）
- `Episode_Reward/reach_goal`: 0% （零）

**矛盾**：终止触发了，但奖励为0。

### 三种可能原因

#### 原因A：奖励阈值 < 终止阈值 ⭐⭐⭐⭐⭐（最可能）

**假设**：
- 终止阈值：0.25m
- 奖励阈值：0.1m（或其他更小的值）
- 结果：机器人进入0.25m圈触发终止，但没进入0.1m圈，不给奖励

**证据**：
```
Episode_Reward/reach_goal: 0.0000
Episode_Termination/reach_goal: 0.7646
```

**验证方法**：
```python
# 检查配置
print(f"Terminations.reach_goal.params: {terminations.reach_goal.params}")
print(f"Rewards.reach_goal.params: {rewards.reach_goal.params}")
```

---

#### 原因B：奖励函数在终止后计算 ⭐⭐⭐⭐

**假设**：
- Isaac Lab的`mdp.terminal_reward`只在`env.reset()`时计算
- 如果终止先触发，`env.reset()`被调用
- 奖励计算在重置**之后**，此时距离已重置

**证据**：
- DRL-robot-navigation项目：
  ```python
  if distance < GOAL_REACHED_DIST:
      target = True
      done = True
      reward = self.get_reward(target, collision, action, min_laser)
  ```
  奖励在终止**之前**计算

**你的项目**：
```python
# 可能是Isaac Lab的默认行为
terminations = TerminationsCfg(
    reach_goal = RewTerm(func=mdp.reach_target_xy, ...)
)
# 奖励可能在reset时才计算
```

---

#### 原因C：函数参数未正确传递 ⭐⭐⭐

**假设**：
```python
rewards.reach_goal = RewTerm(
    func=mdp.terminal_reward,
    params={"threshold": 0.5},  # ❌ 这个参数可能被忽略
    weight=1.0
)
```

`mdp.terminal_reward`可能不接受自定义参数，使用内部硬编码的阈值。

```python
# 在 dashgo_env_v2.py 头部添加
def reward_reach_goal_v2(env) -> torch.Tensor:
    """自定义到达奖励（解决threshold参数不生效问题）"""
    from isaaclab.assets import RobotData

    robot: RobotData = env.scene["robot"]
    target_pos = env.command_manager.get_command("target_position")[:, :2]
    robot_pos = robot.data.root_pos_w[:, :2]

    # 计算距离
    dist = torch.norm(target_pos - robot_pos, dim=-1)

    # 距离<0.5m给100分
    reward = torch.where(dist < 0.5, 100.0, 0.0)

    return reward

# 在配置中使用
@configclass
class RewardsCfg:
    reach_goal = RewTerm(
        func=reward_reach_goal_v2,  # ✅ 使用自定义函数
        weight=1.0
    )
```

### 方案C：借鉴DRL-robot-navigation（渐进式）⭐⭐⭐⭐

**核心思想**：使用已验证的奖励公式

#### 参考奖励公式

```python
# DRL-robot-navigation的奖励函数
def get_reward(target, collision, action, min_laser):
    if target:
        return 100.0  # 到达目标
    elif collision:
        return -100.0  # 碰撞
    else:
        r3 = lambda x: 1 - x if x < 1 else 0.0
        # 前进 + 直行 + 安全
        return action[0]/2 - abs(action[1])/2 - r3(min_laser)/2
```

#### 移植到Isaac Lab

```python
# dashgo_env_v2.py

@configclass
class RewardsCfg:
    # 1. 到达奖励（稀疏但强）
    reach_goal = RewTerm(
        func=reward_reach_goal_v2,
        weight=1.0  # 已经是±100
    )

    # 2. 引导项（DRL-robot-navigation风格）
    forward_bonus = RewTerm(
        func=mdp.lin_vel_x_l2,
        params={"weight": 0.5}  # 鼓励前进
    )

    straight_bonus = RewTerm(
        func=mdp.angular_vel_z_l2,
        params={"weight": -0.5}  # 惩罚转向
    )

    safety_bonus = RewTerm(
        func=mdp.is_close_to_obstacle,  # 或类似函数
        params={"threshold": 0.3, "weight": -1.0}  # 惩罚靠近障碍
    )

    # 3. 碰撞惩罚（保持）
    collision = RewTerm(
        func=mdp.collision_penalty,
        weight=-100.0
    )
```

**优点**：
- ✅ 已在DRL-robot-navigation中验证有效
- ✅ 不依赖复杂的势能场奖励
- ✅ 引导项简洁明确

## 经验教训

### 1. 稀疏奖励的风险

**教训**：
- 只依赖"到达事件"奖励（±100）极难训练
- DRL-robot-navigation成功是因为：
  - 高探索噪声（expl_noise=1.0）
  - 缓慢衰减（50万步）
  - 巧妙的引导项

**对你的启示**：
- 不能只依赖reach_goal奖励
- 必须添加引导项（前进+直行+安全）

---

### 2. 终止与奖励的同步

**教训**：
- DRL-robot-navigation：终止和奖励在同一时刻计算
- 你的项目：可能在不同时刻计算

**对你的启示**：
- 必须确保奖励在终止**之前**计算
- 或者使用自定义函数，明确控制计算顺序

---

### 3. 参数传递的陷阱

**教训**：
- Isaac Lab的`mdp.*`函数可能不接受自定义参数
- 需要验证参数是否生效

**对你的启示**：
- 不依赖函数的隐式行为
- 必要时使用自定义函数

```python
#!/usr/bin/env python3
"""
诊断 reach_goal 奖励为0的问题
"""
import yaml
import torch
from dashgo_env_v2 import DashgoNavEnvV2Cfg

def main():
    print("=" * 60)
    print("Reach Goal 奖励诊断工具")
    print("=" * 60)

    # 1. 加载YAML配置
    print("\n[1] 加载 train_cfg_v2.yaml")
    with open("train_cfg_v2.yaml") as f:
        cfg = yaml.safe_load(f)

    # 2. 打印终止阈值
    print("\n[2] Terminations配置:")
    try:
        term_cfg = cfg['env']['terminations']['reach_goal']
        print(f"  Function: {term_cfg.get('func', 'N/A')}")
        print(f"  Params: {term_cfg.get('params', 'N/A')}")
        print(f"  Weight: {term_cfg.get('weight', 'N/A')}")
    except KeyError as e:
        print(f"  ❌ 配置缺失: {e}")

    # 3. 打印奖励配置
    print("\n[3] Rewards配置:")
    try:
        reward_cfg = cfg['env']['rewards']['reach_goal']
        print(f"  Function: {reward_cfg.get('func', 'N/A')}")
        print(f"  Params: {reward_cfg.get('params', 'N/A')}")
        print(f"  Weight: {reward_cfg.get('weight', 'N/A')}")
    except KeyError as e:
        print(f"  ❌ 配置缺失: {e}")

    # 4. 创建环境实例
    print("\n[4] 创建环境实例...")
    try:
        env_cfg = DashgoNavEnvV2Cfg()
        print(f"  ✅ 环境创建成功")

        print(f"\n[5] 环境实际配置:")
        print(f"  Terminations.reach_goal.params: {env_cfg.terminations.reach_goal.params}")
        print(f"  Rewards.reach_goal.params: {env_cfg.rewards.reach_goal.params}")

    except Exception as e:
        print(f"  ❌ 环境创建失败: {e}")

    # 6. 诊断结论
    print("\n" + "=" * 60)
    print("[诊断结论]")
    print("=" * 60)

    try:
        term_thresh = env_cfg.terminations.reach_goal.params.get('threshold', 'N/A')
        reward_thresh = env_cfg.rewards.reach_goal.params.get('threshold', 'N/A')

        if term_thresh == reward_thresh:
            print(f"✅ 阈值一致: {term_thresh}")
        elif term_thresh > reward_thresh:
            print(f"❌ 终止阈值({term_thresh}) > 奖励阈值({reward_thresh})")
            print(f"   说明: 奖励更难触发，这是问题所在！")
        else:
            print(f"❌ 终止阈值({term_thresh}) < 奖励阈值({reward_thresh})")
            print(f"   说明: 奖励应该先触发，检查函数实现")

    except Exception as e:
        print(f"⚠️  无法比较: {e}")

    print("\n" + "=" * 60)
    print("诊断完成")
    print("=" * 60)

if __name__ == "__main__":
    main()
```
