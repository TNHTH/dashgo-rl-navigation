## 🔍 问题分析

### 根本原因

**架构师诊断**：
> 这是一个非常典型的 **"启动顺序错误"**。
>
> **原因**：Isaac Sim 的 Python 环境非常特殊。所有的核心模块（如 `omni.physics`、`pxr`）只有在 **`AppLauncher` 启动仿真器内核之后** 才能被 Python 找到。
>
> **你的代码错误**：在 `debug_system_check.py` 中，你在启动 App 之前就导入了 `isaaclab.envs`。这时候仿真器还没运行，Python 根本不知道 `omni` 是什么。

**详细解释**：

1. **之前的代码（错误）**：
   ```python
   from isaaclab.app import AppLauncher
   from isaaclab.envs import ManagerBasedRLEnv  # ❌ 太早了！
   from dashgo_env_v2 import DashgoNavEnvV2Cfg

   launcher = AppLauncher({"headless": True})  # App 还没启动
   ```

2. **Isaac Sim 的模块加载机制**：
   - `omni.physics`、`pxr` 等模块不是标准的 Python 包
   - 它们是在 Isaac Sim 仿真器启动时动态加载的
   - 只有调用 `AppLauncher.app` 后，这些模块才会被加入 `sys.path`

3. **违反的铁律**：
   - 这是 **Isaac Lab 开发铁律一**：Python 导入顺序是"生死线"
   - 文档：`docs/05-协议规范/isaac-lab-development-iron-rules.md`

## ✅ 解决方案

### 修改文件：debug_system_check.py

**修改前**（错误）：
```python
from isaaclab.app import AppLauncher
import torch
from isaaclab.envs import ManagerBasedRLEnv  # ❌ 太早

launcher = AppLauncher({"headless": True})
simulation_app = launcher.app
```

**修改后**（正确）：
```python
import argparse
from isaaclab.app import AppLauncher

# [关键] 1. 必须最先初始化 AppLauncher
parser = argparse.ArgumentParser()
AppLauncher.add_app_launcher_args(parser)
args_cli = parser.parse_args()

# 启动仿真器内核
app_launcher = AppLauncher(args_cli)
simulation_app = app_launcher.app

# [关键] 2. 只有在 App 启动后，才能导入 Isaac Lab 的其他模块
import torch
from isaaclab.envs import ManagerBasedRLEnv
from dashgo_env_v2 import DashgoNavEnvV2Cfg
```

**关键改动**：
1. 添加 `argparse` 参数解析
2. 调用 `AppLauncher.add_app_launcher_args(parser)` 注册所有参数
3. 先启动 `AppLauncher`，再导入其他模块

## 📊 技术细节

### Isaac Sim 的模块加载机制

**标准 Python 包**：
```python
import numpy  # 直接从文件系统加载
import torch  # 直接从 site-packages 加载
```

**Isaac Sim 动态模块**：
```python
import omni.physics  # ❌ 失败！仿真器没启动
```

**为什么失败？**
- `omni.physics` 不在文件系统中
- 它是 Isaac Sim 运行时动态创建的模块
- 只有在 `AppLauncher.app` 调用后才会存在

**正确流程**：
```python
from isaaclab.app import AppLauncher

# 1. 启动仿真器
app_launcher = AppLauncher()
simulation_app = app_launcher.app  # ← 这里会加载所有 omni.* 模块

# 2. 现在可以导入了
import omni.physics  # ✅ 成功！
import pxr  # ✅ 成功！
from isaaclab.envs import ManagerBasedRLEnv  # ✅ 成功！
```

## 🎓 经验教训

### 1. Isaac Lab 开发铁律一：导入顺序

**规则**：
> AppLauncher 必须在任何 Isaac Lab 模块或 torch 之前导入

**原因**：
- Isaac Sim 基于 Omniverse Kit 构建
- 如果先导入 `omni.isaac.core`，Python 会尝试在"空壳"环境中寻找仿真器实例
- 导致 `--headless` 参数失效、Segfault、ModuleNotFoundError

**铁律文档**：
- `docs/05-协议规范/isaac-lab-development-iron-rules.md`

### 2. 所有脚本都必须遵守铁律

**范围**：
- ✅ 训练脚本：`train_v2.py`
- ✅ 诊断脚本：`debug_system_check.py`
- ✅ 测试脚本：任何 Isaac Lab 相关脚本

**检查清单**：
- [ ] `AppLauncher` 在第35行之前
- [ ] `simulation_app = app_launcher.app` 在导入 `omni.isaac.*` 之前
- [ ] 所有 Isaac Lab 模块在 App 启动后导入

### 3. argparse 参数注册

**问题**：
- 如果不调用 `AppLauncher.add_app_launcher_args(parser)`
- `--enable_cameras` 等参数会被"吞掉"

**解决**：
```python
parser = argparse.ArgumentParser()
AppLauncher.add_app_launcher_args(parser)  # ← 注册所有 AppLauncher 参数
```
