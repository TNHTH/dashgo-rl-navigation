# numpy版本冲突导致ROS launch启动失败

> **发现时间**: 2026-01-29 16:10:00
> **严重程度**: 🟡 警告（环境问题）
> **状态**: ✅ 已解决
> **相关文件**: catkin_ws/src/dashgo_rl/launch/sim2real_golden.launch

---

## 📋 问题描述

### 错误现象

尝试启动ROS launch文件时失败，错误信息：
```bash
roslaunch dashgo_rl sim2real_golden.launch enable_gazebo:=true enable_move_base:=true
```

**完整错误信息**：
```
ModuleNotFoundError: No module named 'numpy.core._multiarray_umath'

ImportError:
```

**错误路径**：
```
/home/gwh/IsaacLab/_isaac_sim/extscache/omni.kit.pip_archive-0.0.0+d02c707b.lx64.cp310/pip_prebundle/numpy/
```

---

## 🔍 根本原因

### numpy版本冲突

**问题分析**：
1. 用户的环境变量中包含了Isaac Lab的numpy路径
2. Isaac Lab使用的numpy版本与ROS/系统numpy不兼容
3. ROS启动时（特别是gmapping等Python节点）加载了错误的numpy版本

**冲突路径**：
- Isaac Lab的numpy缓存：`/home/gwh/IsaacLab/_isaac_sim/extscache/omni.kit.pip_archive/`
- 系统numpy：`/usr/lib/python3/dist-packages/numpy`

**触发条件**：
- 在source过Isaac Lab环境的终端中启动ROS
- 或PYTHONPATH环境变量包含Isaac Lab路径

---

## ✅ 解决方案

### 方案1：使用干净的终端（推荐）

**步骤**：
1. 打开**全新的终端窗口**（不要运行任何Isaac Lab相关命令）
2. 直接启动ROS：
```bash
cd /home/gwh/dashgo_rl_project
source catkin_ws/devel/setup.bash
roslaunch dashgo_rl sim2real_golden.launch enable_gazebo:=true enable_move_base:=true
```

**原理**：新终端没有加载Isaac Lab的PYTHONPATH，使用系统numpy

---

### 方案2：临时禁用gmapping（备选）

如果新终端仍有问题，可以禁用依赖Python的节点：

```bash
cd /home/gwh/dashgo_rl_project
source catkin_ws/devel/setup.bash
roslaunch dashgo_rl sim2real_golden.launch \
  enable_gazebo:=true \
  enable_move_base:=true \
  enable_gmapping:=false
```

**适用场景**：
- 只需要测试导航（不需要SLAM建图）
- gmapping不是必需的

---

### 方案3：清理PYTHONPATH（临时）

**检查环境变量**：
```bash
echo $PYTHONPATH | grep -i isaac
```

**如果有输出**，临时清理：
```bash
# 方法A：临时取消PYTHONPATH（只影响当前终端）
unset PYTHONPATH
source catkin_ws/devel/setup.bash
roslaunch dashgo_rl sim2real_golden.launch ...
```

**不推荐永久修改PYTHONPATH**，因为这会影响Isaac Lab使用。

## 🔧 预防措施

### 1. 使用独立的终端环境

**推荐做法**：
- **终端1**：专门用于Isaac Lab（训练、仿真）
- **终端2**：专门用于ROS（导航、部署）
- 两个终端互不干扰

### 2. 使用shell脚本隔离

创建启动脚本`start_ros.sh`：
```bash
#!/bin/bash
# 清理可能的环境冲突
unset PYTHONPATH

# 加载ROS环境
source /home/gwh/dashgo_rl_project/catkin_ws/devel/setup.bash

# 启动launch文件
roslaunch dashgo_rl sim2real_golden.launch "$@"
```

### 3. 在`.bashrc`中添加别名

```bash
# 添加到 ~/.bashrc
alias ros-cd='cd /home/gwh/dashgo_rl_project && source catkin_ws/devel/setup.bash'
alias isaac-cd='cd /home/gwh/IsaacLab && source setup.sh'
```

## 💡 经验教训

### 1. 环境隔离的重要性

**问题**：Isaac Lab和ROS使用不同的numpy版本
**解决**：使用独立终端或清理环境变量

### 2. PYTHONPATH的隐式依赖

**问题**：很多ROS节点（特别是Python节点）依赖系统numpy
**解决**：启动ROS前不要source其他大型框架的环境

### 3. 错误信息的解读

**关键线索**：
- 错误路径包含`IsaacLab/_isaac_sim/extscache/`
- 说明Isaac Lab的环境污染了ROS环境
