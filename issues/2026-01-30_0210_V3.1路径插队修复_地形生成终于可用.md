## 架构师的诊断（通过用户转述）

### 根本原因：路径优先级被"劫持"

虽然我们在 `train_v2.py` 里加了路径注入（commit 5511f91），但使用的是 `sys.path.append`（加到末尾）。

**Isaac Sim的环境非常霸道**：
- Isaac Sim在 `sys.path` 的前面有自己的 `omni` 命名空间路径
- Python解释器先在前面找到了Isaac Sim的空壳`omni`，就停止搜索了
- 根本没走到后面去看我们注入的 `Isaac Lab`

**结果**：
- 虽然路径注入了，但优先级不够高
- `omni.isaac.lab` 仍然找不到（被Isaac Sim的`omni`覆盖）
- 地形生成模块导入失败

## V3.1修复方案

### 修复1：train_v2.py - 路径插队抢占优先级

**修改位置**：Lines 32-47

**修改前**（V3.0）：
```python
isaaclab_source_path = os.path.expanduser("~/IsaacLab/source")
sys.path.append(os.path.join(isaaclab_source_path, "isaaclab"))
sys.path.append(os.path.join(isaaclab_source_path, "isaaclab_assets"))
sys.path.append(os.path.join(isaaclab_source_path, "isaaclab_tasks"))
sys.path.append(os.path.join(isaaclab_source_path, "isaaclab_rl"))
```

**修改后**（V3.1）：
```python
# [架构师V3.1补丁] 强力注入 - 使用 insert(0) 抢占优先级
isaaclab_source_path = os.path.expanduser("~/IsaacLab/source")

# 关键修复：使用 insert(0) 确保我们的路径排在 Isaac Sim 自带路径之前
sys.path.insert(0, os.path.join(isaaclab_source_path, "isaaclab"))
sys.path.insert(0, os.path.join(isaaclab_source_path, "isaaclab_assets"))
sys.path.insert(0, os.path.join(isaaclab_source_path, "isaaclab_tasks"))
sys.path.insert(0, os.path.join(isaaclab_source_path, "isaaclab_rl"))

# 调试输出（确认路径插队成功）
print("[DEBUG] Isaac Lab paths inserted at position 0:", sys.path[:4])
```

**关键改进**：
- `sys.path.append` → `sys.path.insert(0, ...)`
- 确保Isaac Lab路径排在sys.path的第一位
- Isaac Sim的omni模块必须在Isaac Lab之后导入

## 架构师原理

### Python模块搜索顺序

```python
import sys
sys.path = [
    "/isaac-sim/kit/omni",           # Isaac Sim的omni（空壳）
    "/isaac-sim/kit/omni.isaac",   # Isaac Sim的omni.isaac
    "/home/user/IsaacLab/source/isaaclab",  # ✅ 我们的路径（如果append）
    ...
]
```

**问题**：
- Python从前往后搜索
- 先找到Isaac Sim的空壳`omni`
- 不会继续往后找我们的`isaaclab`

**修复**：
```python
import sys
sys.path = [
    "/home/user/IsaacLab/source/isaaclab",  # ✅ insert(0)插到第一位
    "/isaac-sim/kit/omni",           # Isaac Sim的omni
    "/isaac-sim/kit/omni.isaac",   # Isaac Sim的omni.isaac
    ...
]
```

## 经验教训

### 1. sys.path优先级至关重要

**教训**：
- Isaac Sim有自己的omni命名空间，会"劫持"模块搜索
- `sys.path.append`（末尾）可能不够
- `sys.path.insert(0, ...)`（开头）确保优先级

**最佳实践**：
- 在有多个Python环境共存时，使用`insert(0)`
- 确认关键路径在最前面

---

### 2. 拒绝妥协式的错误处理

**教训**：
- try-except回退到GroundPlane会导致无效训练
- "掩耳盗铃"会让问题被掩盖
- 必须强制要求环境配置正确

**最佳实践**：
- 关键功能直接硬导入，失败即报错
- 不要用try-except掩盖导入错误
- 宁可训练无法启动，也不要无效训练

---

### 3. 架构师的路径优先级原理

**原理**：
- Isaac Sim的omni模块 → Isaac Lab的isaaclab → 用户代码
- 导入顺序决定模块覆盖关系
- Python的模块搜索是"先到先得"

**应用**：
- 必须先导入Isaac Lab，再导入AppLauncher
- AppLauncher会初始化Isaac Sim环境
- 然后才能使用omni模块
