## 🔴 问题1: reset_buf属性不存在

### 错误信息

```
File "/home/gwh/dashgo_rl_project/dashgo_env_v2.py", line 541, in curriculum_adaptive_distance
    dones = env.reset_buf[env_ids]
AttributeError: 'ManagerBasedRLEnv' object has no attribute 'reset_buf'
```

### 根本原因

**API版本不匹配**：
- 使用了旧版OpenAI Gym的`env.reset_buf` API
- Isaac Lab 4.5已移除此属性
- `env_ids`参数已指明重置的环境，无需额外查询

### 错误代码

```python
# ❌ 错误实现（旧版Gym API）
def curriculum_adaptive_distance(env, env_ids, ...):
    # 尝试访问不存在的属性
    dones = env.reset_buf[env_ids]
```

### 修复方案（架构师提供）

**核心修改**：
1. 移除`env.reset_buf`调用
2. 使用`env.extras["log"]["success"]`获取成功率
3. 添加`is_startup`检查保护（首次运行extras为空）

**修复代码**：
```python
def curriculum_adaptive_distance(env, env_ids, ...):
    # ✅ 直接使用env_ids
    is_startup = not env.extras or "log" not in env.extras

    if not is_startup:
        successes = env.extras["log"]["success"][env_ids].float()
        # 处理成功率...
```

## 🔴 问题2: 返回值类型错误

### 错误信息

```
File "/home/gwh/dashgo_rl_project/dashgo_env_v2.py", line 116, in reset
    term_state = term_state.item()
RuntimeError: a Tensor with 20 elements cannot be converted to Scalar
```

### 根本原因

**Curriculum Manager接口要求**：
- 返回值必须是**标量Tensor**（0-d Tensor）
- Curriculum Manager调用`.item()`转换为Python float
- 用于记录到TensorBoard

**错误代码**：
```python
# ❌ 返回向量（20个元素）
return torch.full((len(env_ids),), current_dist, device=env.device)
# RuntimeError: 不能转换为Scalar
```

### 修复方案（架构师提供）

**核心修改**：
1. 返回标量Tensor：`torch.tensor(current_dist)`
2. **关键增强**：实际修改Command Manager配置
3. 异常处理避免刷屏

**修复代码**：
```python
# ❌ 旧代码
return torch.full((len(env_ids),), current_dist, device=env.device)

# ✅ 新代码（标量）
return torch.tensor(current_dist, device=env.device)

# 🔥 核心增强：实际修改命令生成器
cmd_term = env.command_manager.get_term("target_pose")

# 修改极坐标范围
if hasattr(cmd_term.cfg.ranges, "r"):
    cmd_term.cfg.ranges.r = (initial_dist, current_dist)

# 或修改笛卡尔坐标范围
elif hasattr(cmd_term.cfg.ranges, "pos_x"):
    half_dist = current_dist
    cmd_term.cfg.ranges.pos_x = (-half_dist, half_dist)
    cmd_term.cfg.ranges.pos_y = (-half_dist, half_dist)
```

**额外收益**：
- 修复前：统计数据更新但难度未实际生效
- 修复后：Command Manager配置实际修改，难度真正变化

**修复Commit**: `0b250a0`

## 🎓 经验教训

### 1. API版本兼容性

**问题**：直接使用旧版Gym API导致失败

**解决**：
- ✅ 检查Isaac Lab 4.5官方文档
- ✅ 使用`env.extras`替代`env.reset_buf`
- ✅ `env_ids`参数已足够，无需额外查询

### 2. 返回值类型规范

**问题**：Curriculum Manager期望特定类型

**解决**：
- ✅ 标量Tensor：`torch.tensor(value)`
- ✅ 向量Tensor：`torch.full(size, value)`（错误）
- ✅ 查看官方示例确认返回值类型

### 3. Side Effect的重要性

**发现**：只统计数据不够，必须实际修改配置

**解决**：
- ✅ 修改`cmd_term.cfg.ranges`
- ✅ 验证Command Manager实际生效
