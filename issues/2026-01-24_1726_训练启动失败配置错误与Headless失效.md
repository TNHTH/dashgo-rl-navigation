# 训练启动失败：配置错误与Headless失效

> **创建时间**: 2026-01-24 17:26:00
> **问题类型**: Bug
> **严重程度**: 🔴 严重（阻塞训练）
> **状态**: ✅ 已修复

---

## 📋 问题描述

启动训练时遇到两个关键问题：

1. **KeyError: 'num_steps_per_env'** - RSL-RL 配置结构不匹配
2. **--headless 参数失效** - Isaac Sim 窗口仍然弹出

---

## 🔍 问题1：配置 KeyError

### 错误信息
```python
Traceback (most recent call last):
  File "/home/gwh/dashgo_rl_project/train_v2.py", line 194, in main
    runner = OnPolicyRunner(env, agent_cfg, log_dir=log_dir, device=device)
  File "/home/gwh/.conda/envs/env_isaaclab/lib/python3.10/site-packages/rsl_rl/runners/on_policy_runner.py", line 36, in __init__
    self.num_steps_per_env = self.cfg["num_steps_per_env"]
KeyError: 'num_steps_per_env'
```

### 根本原因

**YAML 结构**：
```yaml
# train_cfg_v2.yaml
runner:
  num_steps_per_env: 24  # 嵌套在 runner 下
```

**Python 加载**：
```python
train_cfg = yaml.safe_load(f)
# 结果：{'runner': {'num_steps_per_env': 24, ...}, ...}
```

**RSL-RL 期望**：
```python
# rsl_rl/runners/on_policy_runner.py:36
self.num_steps_per_env = self.cfg["num_steps_per_env"]  # 直接在根目录找
```

**问题**：RSL-RL 直接在根目录查找 `num_steps_per_env`，但它在 `runner` 子目录下。

### 解决方案

**修复代码**：
```python
# 将 runner 里的参数提取到根目录
agent_cfg = train_cfg.copy()
if "runner" in agent_cfg:
    runner_cfg = agent_cfg.pop("runner")
    agent_cfg.update(runner_cfg)  # 把 num_steps_per_env 提到根目录
```

## 🎨 问题2：Headless 失效

### 错误现象
- 用户输入：`~/IsaacLab/isaaclab.sh -p train_v2.py --headless --num_envs 80`
- **结果**：仍然弹出 Isaac Sim 窗口显示场景

### 根本原因

**原因**：`train_v2.py` 没有参数解析（ArgumentParser）模块

**机制**：
1. `isaaclab.sh` 传递 `--headless` 参数给 Python 脚本
2. 但 `train_v2.py` 没有代码"读取"这个参数
3. 仿真器默认以 GUI 模式启动

**错误代码**：
```python
# train_v2.py (旧版)
import gymnasium as gym
from omni.isaac.lab.envs import ManagerBasedRLEnv

# ❌ 缺少 AppLauncher 和 ArgumentParser
# ❌ 直接导入 Isaac Lab，导致窗口弹出
```

### 解决方案

**正确顺序**：
```python
# 1. 在导入任何 omni/isaac 模块之前，先初始化 AppLauncher
from omni.isaac.lab.app import AppLauncher

# 2. 创建参数解析器
parser = argparse.ArgumentParser(description="DashGo RL Training")
parser.add_argument("--headless", action="store_true", default=False)

# 3. 解析参数
args_cli = parser.parse_args()

# 4. 启动仿真应用
app_launcher = AppLauncher(headless=args_cli.headless)
simulation_app = app_launcher.app

# 5. 然后才能导入其他库
import gymnasium as gym
from omni.isaac.lab.envs import ManagerBasedRLEnv
```

**关键**：`AppLauncher` 必须在所有 Isaac Lab 模块**之前**导入和初始化。

## 🛠️ 修复方案

### 文件：train_v2.py

**完整修复代码**：

```python
# train_v2.py
# 2026-01-24: Fixed by Isaac Sim Architect
# 修复内容：
# 1. 增加 ArgumentParser 支持 --headless 和 --num_envs
# 2. 修复 RSL-RL 配置 KeyError 问题
# 3. 显存保护：启动前清理 CUDA 缓存

import argparse
import sys
import os

# [关键步骤 1] 在导入任何 omni/isaac 模块之前，先初始化 AppLauncher
# 这是让 --headless 生效的唯一方法
from omni.isaac.lab.app import AppLauncher

# 创建参数解析器
parser = argparse.ArgumentParser(description="DashGo RL Training Script")
parser.add_argument("--headless", action="store_true", default=False, help="Run in headless mode")
parser.add_argument("--num_envs", type=int, default=None, help="Number of environments to simulate")
parser.add_argument("--seed", type=int, default=42, help="Random seed")

# 解析参数 (isaaclab.sh 会把参数传进来)
args_cli = parser.parse_args()

# 启动仿真应用
app_launcher = AppLauncher(headless=args_cli.headless)
simulation_app = app_launcher.app

# [关键步骤 2] 仿真器启动后，再导入其他库
import gymnasium as gym
import torch
import yaml
from datetime import datetime

# 导入 Isaac Lab 和 RSL-RL
from omni.isaac.lab.envs import ManagerBasedRLEnvCfg
from rsl_rl.runners import OnPolicyRunner

# 导入我们的环境配置
from dashgo_env_v2 import DashGoEnvCfg

def main():
    """训练 DashGo 导航策略"""

    # 1. 配置环境
    env_cfg = DashGoEnvCfg()

    # 如果命令行指定了环境数量，覆盖配置 (你的显卡推荐 80-128)
    if args_cli.num_envs is not None:
        env_cfg.scene.num_envs = args_cli.num_envs
    else:
        # 默认值，适配 4060 Laptop (8GB VRAM)
        env_cfg.scene.num_envs = 64

    print(f"[Isaac Sim] Env count: {env_cfg.scene.num_envs}, Headless: {args_cli.headless}")

    # 2. 创建 Isaac Lab 环境
    # 直接实例化 ManagerBasedRLEnv (更稳定的方式)
    from omni.isaac.lab.envs import ManagerBasedRLEnv
    env = ManagerBasedRLEnv(cfg=env_cfg)

    # 3. 加载 RSL-RL 训练配置
    # 确保 config/train_cfg_v2.yaml 路径正确
    config_path = os.path.join(os.path.dirname(__file__), "config", "train_cfg_v2.yaml")
    # 如果 config 文件夹在同级目录
    if not os.path.exists(config_path):
        config_path = "train_cfg_v2.yaml" # 尝试直接读取当前目录

    with open(config_path, 'r') as f:
        train_cfg = yaml.safe_load(f)

    # [关键修复 3] 处理 RSL-RL 的配置结构问题 (KeyError Fix)
    # RSL-RL 需要扁平化的配置，我们将 'runner' 里的内容提取到最外层
    agent_cfg = train_cfg.copy()
    if "runner" in agent_cfg:
        runner_cfg = agent_cfg.pop("runner")
        agent_cfg.update(runner_cfg) # 把 num_steps_per_env 提到根目录

    # 确保 algorithm 和 policy 也在 (通常 YAML 里本来就在根目录或者被包含)
    # 我们的 YAML 结构是 algorithm: ..., policy: ... 所以不需要额外操作

    # 4. 初始化 Log 目录
    # 使用时间戳防止覆盖
    run_name = f"{agent_cfg.get('experiment_name', 'dashgo')}_{datetime.now().strftime('%Y-%m-%d_%H-%M-%S')}"
    log_dir = os.path.join("logs", "rsl_rl", run_name)
    os.makedirs(log_dir, exist_ok=True)

    # 5. 初始化 PPO Runner
    # 显存优化：强制清理一下
    torch.cuda.empty_cache()

    runner = OnPolicyRunner(
        env=env,
        train_cfg=agent_cfg, # 传入修复后的配置
        log_dir=log_dir,
        device="cuda:0"
    )

    # 6. 开始训练
    max_iterations = agent_cfg.get("max_iterations", 1500)
    print(f"[Isaac Sim] Starting training for {max_iterations} iterations...")

    runner.learn(num_learning_iterations=max_iterations, init_at_random_ep_len=True)

    print("[Isaac Sim] Training finished.")
    env.close()

if __name__ == "__main__":
    main()
```

## 📝 经验总结

### 关键要点

1. **AppLauncher 必须最先导入**
   - 在所有 omni/isaac 模块之前
   - 否则 headless 参数不生效

2. **RSL-RL 配置需要扁平化**
   - `runner` 子目录的参数要提取到根目录
   - 使用 `pop()` + `update()` 实现

3. **参数解析是必须的**
   - 否则命令行参数全部失效
   - `argparse` 是标准做法

### 常见陷阱

1. ❌ 导入顺序错误
2. ❌ 配置结构不匹配
3. ❌ 忘记解析命令行参数
4. ❌ 配置文件路径错误
